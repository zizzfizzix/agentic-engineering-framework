**shadcn/ui** components (add with `npx shadcn@latest add <name>`):

- `Button`, `Input`, `Select`, `Form` — form building blocks
- `Table` + `DataTable` recipe — list views
- `Dialog`, `Sheet` — modals and drawers
- `Badge` — status indication (use variant, not a colored span)
- `Card` — section containers

Compose these before writing custom markup.
