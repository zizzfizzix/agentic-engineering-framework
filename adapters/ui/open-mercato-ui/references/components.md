**@open-mercato/ui** components:

- `CrudForm`, `FormField`, `FormHeader`/`FormFooter` — forms
- `DataTable` — list views with filters, row + bulk actions
- `SectionHeader`, `Card` — layout
- `StatusBadge` — status indication
- `LoadingMessage`, `ErrorMessage` — required loading/error states

Always build admin screens from these before custom markup.
