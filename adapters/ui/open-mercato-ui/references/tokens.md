**@open-mercato/ui** semantic tokens (Tailwind preset):

| Token | Use for |
|-------|---------|
| `text-fg` / `bg-surface` | base text + surface |
| `text-muted` | secondary text |
| `StatusBadge` tones | success / warning / danger / info status |
| `border-subtle` | dividers |

Use `StatusBadge` for status — never `text-red-600` / `bg-green-100` literals.
